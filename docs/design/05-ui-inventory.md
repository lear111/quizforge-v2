# 界面清单与原型计划

> **文档版本：** v0.1（初稿，待评审）
> **日期：** 2026-10-27
> **依据：** [ADR-006 复用前端](../adr/ADR-006-frontend-reuse.md)，[API 设计](02-api.md)，[题库共享与版本更新](04-bank-sharing-and-updates.md)，需求 FR-01～FR-10

前端复用旧代码（ADR-006），因此**不为所有页面画原型**。本文先列出全部页面和弹窗，标明它们在 V2 中是原样复用、需要修改、新增还是删除；然后只为“修改”和“新增”的部分制作原型，评审通过后再写代码。

**来源：** `quizforge_hub/java-hub/src/main/resources/static`（题库广场与管理后台）、`quizforge_web/core/web`（练习空间）@ 本仓库遗留文档所记录的提交。

## 1. 站点结构

旧系统是**两个网站**：题库广场 `quizforge.treenewbee.cloud` 与练习空间 `practice.treenewbee.cloud`，两者之间通过跨站单点登录跳转（`cloud/hub-login.mjs`）。

V2 后端是一个应用（ADR-001），前端也合并为**一个网站**：

| 路径 | 内容 | 来源 |
| --- | --- | --- |
| `/` | 题库广场：浏览、搜索、详情、上传、我的分享、个人中心、软件下载 | 旧 Hub 页面 |
| `/practice/` | 练习空间：我的题库、作答、历史、考试 | 旧 Web 练习前端 |
| `/admin/` | 管理后台 | 旧 Hub 管理页面 |
| `/connect/authorize` | 设备授权确认页（C-05） | 旧 Hub |

合并后的好处：

- 同一个域名、同一个 Cookie，不再需要跨站单点登录，消除了旧系统中一整套跳转与会话同步逻辑；
- 广场与练习空间之间可以直接链接。

旧练习域名 `practice.treenewbee.cloud` 在切换后**永久重定向**到新地址（API 设计待定项 API-2）。

## 3. 原型计划

### 3.1 范围

需要原型的界面共 8 组：

1. 练习空间整体框架：统一导航 + AI 侧边栏位置（桌面与手机）
2. 题库详情：“加入我的题库”与按本选择
3. 我的题库列表：更新状态标记
4. 题库概览：“有新版本”提示
5. 作答区状态：本题已更新、保存冲突、暂不可用
6. 得分卡：完成后将更新的提示
7. AI 辅导侧边栏：答题中与已评分两种状态
8. 上传新版本与“我的分享”中的版本状态

### 3.2 做法

- **沿用旧前端的视觉风格**（现有主题、配色、圆角与间距），原型只表达新增的内容和交互，不重新设计整体外观。
- 每组画**桌面**与**手机**两个尺寸（练习空间在手机上使用频繁，FR-03）。
- 原型是可以点击查看的静态页面，**不包含真实逻辑**；用于评审交互与文案，也用来检查接口是否返回了界面需要的字段。
- 评审中发现的接口缺口，回写到 API 设计与数据库设计。

### 3.3 原型评审要点

| 检查项 | 问题 |
| --- | --- |
| 文案 | 用户能否看懂“更新”“中断”“作者已移除”分别意味着什么 |
| 打扰程度 | 更新提示是否过于打扰正在刷题的用户 |
| 手机端 | AI 侧边栏、提示条在小屏幕上是否遮挡作答区 |
| 接口字段 | 界面上每一项信息，接口是否都提供了 |
