# 练习空间验收清单

> **版本：** v0.1
> **日期：** 2026-11-01
> **作者：** 王国松（产品规则），Claude 整理
> **用途：** 路线图 v0.2 当前阶段的验收标准：用作者的真实旧题库走通完整练习流程，并确认与旧版同样好用。

## 1. 页面布局

| 区域 | 内容 |
| --- | --- |
| 左侧 | 我的题库（题库分组目录） |
| 中间 | 题目渲染区：由拓展决定样式，默认是题卡 |
| 右侧 | 题库大纲；以后 AI 辅导也放在这里 |

## 2. 一道题在不同状态下能做什么

| 状态 | 作答 | 再试一次 | 改主观题分数 | 白板 |
| --- | --- | --- | --- | --- |
| 作答中（未提交） | 可以修改 | — | — | 随意书写、修改 |
| 单题已提交（完成练习之前） | 只能查看 | 可以 | 可以 | 可以继续书写，作为笔记 |
| 完成练习之后 | 只能查看 | 不可以 | 可以 | 只能追加笔记；完成练习之前的草稿锁定，不能修改或擦除 |
| 历史记录 | 只能查看 | 不可以 | 不可以 | 只能追加笔记 |

## 3. 完成练习

- 对所有“已作答但未提交”的题批量提交并评分；未作答的题保持未作答。
- 之后整本题库只能查看；主观题仍可人工改分；不能再试一次；不能修改完成练习之前的作答与草稿。

## 4. 历史记录

- **顺序固定**：作答 → 完成练习 → 再练一次。**“再练一次”只能在完成练习之后进行**；未完成时按钮不可用，接口拒绝（`PRACTICE_NOT_FINISHED`）。
- **以题库为单位**：一轮练习对应一条历史记录，在用户点击“再练一次”时生成。
- **包含所有题目**：由于完成练习已把所有作答过的题提交并评分，历史中每道题只有两种状态：已提交（含评分）或未作答。记录题目、作答、评分、解析、白板（含完成练习之后追加的笔记）。
- **每道题只保留最后一次尝试**：同一轮中多次“再试一次”，历史中只看得到最后一次。实现上即在点击“再练一次”时冻结每道题的当前状态。
- 历史记录只能查看，可以追加笔记，不能改分。
- 用户可以手动删除历史记录。
- **删除题库时，该题库的历史记录（含笔记）一并删除**，其引用的文件随之释放。
- **导出 / 导入题库不包含历史记录**（题库包只有内容，没有用户数据）。
- **为以后 AI 分析作答记录预留信号**：每道题额外记录本轮尝试次数、第一次提交的对错、评分来源（规则 / AI / 人工）。不记录作答时长。AI 可读的统一摘要（题目文字、用户作答、参考答案、解析）以后由拓展的可选钩子提供，见 AI 设计。

## 5. 答题区

- 可以打字、插入图片、手写。
- 提交时自动截图，截图作为作答的一部分保存，并在以后作为 AI 评分的图片输入。

## 6. 历史快照的长期保存

目标：软件升级、题库升级、拓展升级之后，历史记录仍然显示为当时的样子。

| 内容 | 保存方式 | 为什么升级后不变 |
| --- | --- | --- |
| 题库结构（标题、题序、大纲、分组） | 冻结为 JSON 存入历史 | 复制了当时的值，不再引用当前题库 |
| 每道题显示的内容 | 冻结**拓展生成的投影结果**（已提交题为提交后投影，含解析），不冻结题库原始数据 | 不需要以后重新执行规则；规则或拓展升级不影响 |
| 作答、评分、状态、白板 | 冻结为 JSON | 复制了当时的值 |
| 拓展页面代码 | 只记录 `extension_digest` | 拓展包按摘要不可变，永远能取回当时的版本 |
| 图片（题库资源、答题图片、提交截图） | 只记录 SHA-256 | 文件按内容寻址、不可变 |
| 共享组件（答题区、富文本） | 拓展声明的固定版本 | 宿主承诺永久提供每个已发布版本 |

要求：

1. **垃圾回收必须把历史的引用算在内**：被任何历史记录引用的拓展包、题库资源、用户上传的图片都不能删除。删除历史（或删除题库连带删除历史）后才释放。
4. **违规内容强制删除**：管理员因版权或违规下架时，强制删除文件，即使仍被引用；历史中对应位置显示“该资源已被管理员移除”，题目结构、作答与评分照常显示。管理员的强制删除优先于历史保留。
2. **快照带格式版本号**（例如 `snapshotVersion`）：以后改变快照结构时，新版宿主仍能读取旧格式。
3. **宿主保持 Extension API 兼容**：历史页面以 `history` 模式加载当时的拓展页面，宿主不得删除旧版 API 能力；用冻结的快照样例做回归测试。

## 7. 存储配额与下载流量（沿用旧平台）

| 限制 | 默认值 | 计入 | 不计入 |
| --- | --- | --- | --- |
| 个人存储 | 256 MiB，管理员可按用户调整 | 私人导入的题库（展开后大小）、上传的答题图片与截图、练习数据（草稿、白板、历史） | 题库广场的公共题库 |
| 每日下载流量 | 256 MiB，按北京时间每日重置，管理员可按用户调整 | 导出题库、下载题库文件 | 正常练习、读题与读图、页面静态资源 |

- 上传、保存白板、插入图片、导入等写入操作在同一事务内检查并记账配额，并发不能超用。
- 内容寻址去重后，相同内容被多个用户私人导入时，**每个用户各自计入**（按“我导入了多少”而不是物理占用计算），避免用量随他人操作变化。
- 删除私人题库（连带历史）、删除历史记录可以释放空间。
- 用户中心显示存储已用 / 额度、今日下载已用 / 额度。
