## I. 站内通知中心（2026-11-01 决定）—— Codex，随题库广场

| 来源 | 内容 | 接收者 |
| --- | --- | --- |
| 题库发布者 | 题库升级说明（发布新版本时由发布者填写） | 已经使用该题库的用户 |
| 管理员 | 站内公告；管理员联系方式作为一条置顶通知 | 第一版发给所有人；用户分组等以后再做 |
| 系统 | 审核结果等 | 相关用户 |

- **管理员**：新建、查看、删除、置顶；**不能修改**（要改就删除重发）。所有操作记入审计日志，记录发送的管理员。
- **用户**：顶部铃铛图标，有新通知时显示红点；**打开通知界面后铃铛红点消失**，即使没有逐条查看。通知界面是列表，每条显示标题与发布时间；**未查看的通知各自带红点**，点开查看后消失。置顶通知排在最前。
- 设计要点：发给所有人的通知只存一份，不为每个用户复制一行；铃铛红点用“用户上次打开通知界面的时间”判断，单条已读用“用户 × 通知”的已读记录；题库升级通知按“用户是否拥有该题库”在读取时筛选。
