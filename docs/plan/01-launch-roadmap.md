## 2. 当前阶段：用真实题库打通完整练习流程（v0.2 调整）

此前以横向推进为主（并发、幂等、性能），用户能看到的完整流程一直没有打通：旧题库无法在新版使用、很多功能只能看测试报告。当前阶段改为**纵向推进**：以作者的一本真实旧题库（含答题区组件与 AI 评分）为标准，打通

```text
导入（转换为格式 4）→ 打开题库、大纲 → 答题（选择、简答、答题区打字 / 插图 / 手写）→ 保存草稿、刷新恢复
→ 单题提交（答题区截图）→ 人工评分 → 完成练习、汇总 → 历史记录回顾 → 再练一轮
```

**验收标准：** 这条流程完整走通，且作者亲自确认与旧版同样好用。题库广场、考试模式、AI 暂缓。

| 顺序 | 任务 |
| --- | --- |
| 1 | 题库转换工具（格式 3 → 4） |
| 2 | L1.5 答题区：上传答题资源、白板、提交截图（可与 1 并行） |
| 3 | L1.3 完成练习、L1.4 历史记录 |
| 4 | L1.6 小题草稿状态 |
| 5 | 作者对照旧版逐项验收，差异整理为修复任务 |

验收清单由作者根据旧版的实际使用列出（见 `docs/plan/02-practice-acceptance.md`，待补）。

## 3. 上线前的里程碑

按依赖关系排序；同一里程碑内的任务可以拆成多个 PR。

### L1 练习闭环补全（FR-03、FR-14）

让网页端练习达到旧平台的完整体验。

| 任务 | 接口 / 说明 |
| --- | --- |
| L1.1 重做本题、人工评分 | `actions` 的 retry / review；人工打分以最后一次为准（FR-14） |
| L1.2 本轮汇总、再练一轮 | `GET C/summary`、`POST C/restart`（数据库设计 5.4、5.5） |
| L1.3 完成练习 | `POST C/finish`：批量提交未提交题、异步判分与进度、完成后可改分不可单题重练 |
| L1.4 历史记录 | 历史列表、冻结快照查看、删除；历史批注（只追加） |
| L1.5 白板与答题资源 | `whiteboard` 动作、`POST /api/resources` |
| L1.6 小题草稿状态 | 保存草稿时调用 `validateAnswer`，写入 `outline_states` |
| L1.7 我的题库管理 | 改名、分组、移动到根目录、删除、导出 |

### L2 题库内考试模式（FR-03）

考试列表与开始、考试中只能保存草稿和白板、整卷交卷、**服务器到期自动交卷**（定时任务，交卷幂等）、交卷后批量判分。

### L3 题库广场与分享（FR-02、FR-10、FR-11、FR-12）

| 任务 | 说明 |
| --- | --- |
| L3.1 管理员审核 | 管理员角色；审核页面（题库、拓展白名单）；**导入时为未知拓展自动创建 pending 记录**（目前缺失） |
| L3.2 题库广场 | 浏览、搜索、详情、加入“我的题库” |
| L3.3 发布与分享 | 从本地上传或从云端私人题库发布；按题库 UUID 对应新旧版本；整包更新 |
| L3.4 收藏与更新 | 收藏；用户主动更新到新版本（无进行中作答时整本切换） |
| L3.5 通知 | 审核结果等站内通知（只记录发送的管理员） |

### L4 账号补全（FR-01、Issue #20）

手机号注册登录、短信 / 邮件验证码、找回密码、封禁用户不能登录、管理员修改 AI 余额与封禁状态。

### L5 AI（FR-08、FR-14）

| 任务 | 说明 |
| --- | --- |
| L5.1 AI 余额与流水 | 扣费与流水同一事务；余额 = 流水之和 |
| L5.2 模型接入 | 统一调用、超时、重试、限流（Redis） |
| L5.3 AI 辅导 | 多会话、流式输出（SSE）、未提交时模型拿不到答案、服务器查询作答状态 |
| L5.4 AI 判分 | 拓展提供上下文、宿主提取分值；异步任务（消息队列 + Outbox）；人工打分中断 AI；提交后自动 AI 评分 |

### L6 客户端兼容（C-05）

Windows / Android 客户端调用的 Hub 接口：设备授权（客户端重新授权一次）、题库下载与固定版本导入（新格式、128 MiB 上限）、AI 连接。需要先补全遗留契约 V-1（完整请求、响应与错误码）。

### L7 数据迁移（FR-09）

迁移账号（含只有手机号的用户、原密码可登录）与 AI 余额及全部流水；在旧库副本上演练并出校验报告；回退演练。

### L8 上线工程

生产 compose 与 HTTPS、密钥与令牌缺省值启动即失败、数据库与文件备份及恢复演练、日志与监控告警、在真实 4 核 8G 上复测、切换与回退方案。
